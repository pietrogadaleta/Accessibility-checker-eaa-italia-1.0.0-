# Accessibility-checker-eaa-italia-1.0.0-
Free WordPress plugin for per l'accessibility eaa tutto in Italiano
WordPress accessibility checker for the European Accessibility Act, in Italian. Scans pages, posts and WooCommerce products for WCAG 2.2 AA issues with axe-core, explains how to fix them, applies server-side quick fixes and creates a PDF report and accessibility statement. No overlay, no external services, no Core Web Vitals impact.
